# Warehouse Studio 3D · V8.3 Static

설치나 별도 서버 없이 브라우저에서 창고 설비, 랙, 팔레트와 박스를 배치하는 정적 웹 애플리케이션입니다. 작업본은 브라우저 저장소에 자동 보관하며, 중요한 도면은 JSON으로 내보내 GitHub의 `layouts/` 폴더에 등록할 수 있습니다.

## 바로 배포하기

1. GitHub에서 새 저장소를 만듭니다.
2. 이 폴더 안의 모든 파일과 폴더를 저장소 최상위에 업로드합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Deploy from a branch**를 선택합니다.
5. Branch를 `main`, 폴더를 `/ (root)`로 지정하고 저장합니다.
6. 배포가 완료되면 표시되는 Pages 주소로 접속합니다.

GitHub Enterprise에서는 조직의 Pages 정책에 따라 메뉴 이름이나 주소 형식이 조금 다를 수 있지만, 저장소 최상위의 `index.html`을 배포하는 방식은 같습니다.

3D 렌더링 라이브러리 Three.js는 GitHub Pages에서 jsDelivr CDN으로 불러옵니다. 사내망에서 `cdn.jsdelivr.net`이 차단돼 있다면 해당 도메인을 허용 목록에 추가해 주세요.

## 주요 기능

- 창고 가로·세로·높이 설정
- 팔레트랙, **박스랙**, 선반, 컨베이어, 팔레트, 박스, 지게차, 도크, 작업대 배치
- 클린부스, 의자, 테이핑기, 볼륨체크기, **ERS 촬영 설비** 배치
- 물류센터용 **고중량 전자저울**, 무선 바코드 스캐너, 일반 프린터 배치
- ERS(Evidence Record System)는 물류 증거사진 촬영 구역을 카메라·조명·컨베이어 형상으로 표시
- 휴게실, 사무실, 탈의실과 길이·높이를 조절할 수 있는 구역 분리용 파티션, 자유 문구용 일반 텍스트 배치
- 작업자, 컴퓨터, 라벨 프린터, CCTV, 소화기, 안전콘·펜스, 구급함, 분전반, 폐기물함, 핸드 팔레트 배치
- 사람 출입문과 문구를 직접 바꿀 수 있는 안내·경고 표지판
- 객체 선택, 마우스 이동, 회전, 복제, 삭제
- 카테고리 선택과 설비명 검색으로 라이브러리 빠르게 필터링
- 새 객체를 공중에 생성한 뒤 위치 확인 및 **바닥으로 내리기**
- 카메라 검토용 **전체 잠금**과 설비별 변경 방지용 **객체 잠금**(JSON에 잠금 상태 저장)
- 모든 객체의 `W × D × H` 치수 표시 켜기·끄기
- 숫자로 X·Y·Z 위치와 규격 정밀 입력(벽면 설비 높이 배치 포함)
- 랙 베이·단수·단당 팔레트 설정 및 보관 로케이션 자동 계산
- 박스랙 칸 수·단 수·칸당 박스 수 설정 및 총 BOX 용량 자동 계산
- 팔레트별 박스 규격·최대 적재 높이 설정 및 BOX 수용량 자동 계산
- **총 BOX 수용량** 실시간 합산: 박스랙 용량 + 팔레트 용량 + 바닥·독립 적재 박스
- 박스를 팔레트 또는 다른 박스 위로 끌어 놓는 수동 적재
- 동일 규격 박스의 팔레트 자동 적재
- 객체 겹침 경고
- TOP/3D 보기, 격자 표시, 이동 스냅
- 브라우저 저장, JSON 내보내기·불러오기
- `layouts/` 폴더의 공용 기준 도면 목록·검색·불러오기
- 현재 3D 화면 PNG 저장
- 실행 취소·다시 실행
- WebGL을 사용할 수 없는 환경의 2D 호환 모드

## 사용 방법

1. 왼쪽 **창고 규격**에서 실제 창고 크기를 입력합니다.
2. 카테고리와 검색으로 설비를 찾은 뒤 카드를 클릭하거나 화면으로 끌어 놓습니다. 새 객체는 식별하기 쉽도록 공중에 생성되며, 오른쪽 **바닥으로 내리기**로 Z=0에 놓을 수 있습니다.
3. 박스를 팔레트 또는 이미 놓인 박스 위로 끌면 높이를 찾아 자동으로 얹힙니다. 팔레트나 아래 박스를 옮기면 그 위 적재 묶음도 함께 움직입니다.
4. 배치된 객체를 선택하고 오른쪽에서 X·Y·Z 위치, 회전, 크기를 수정합니다.
5. 박스랙을 선택하면 오른쪽에서 총 보관 가능 박스 수를 확인할 수 있습니다.
6. 팔레트를 선택해 사용할 박스의 가로·세로·높이와 최대 총높이를 입력하면 팔레트 수용량이 계산됩니다.
7. 화면 하단 **총 BOX 수용량**에서 `박스랙 + 팔레트 + 바닥 박스`의 합계와 항목별 내역을 확인합니다.
8. 안내·경고 표지판을 선택해 문구를 직접 입력하거나 ‘지게차 주의’, ‘출입 금지’, ‘안전모 착용’, ‘비상구’ 등의 문구를 고릅니다.
9. 일반 텍스트를 선택하면 최대 40자의 자유 문구를 입력할 수 있습니다.
10. 화면 위 **치수**를 켜면 모든 객체의 W·D·H가 표시됩니다. **전체 잠금** 또는 `L` 키를 누르면 객체 선택 없이 카메라만 조작할 수 있습니다.
11. 중요한 객체는 오른쪽 또는 객체 목록의 자물쇠로 개별 잠금합니다.
12. 상단 **기준 도면**에서 `layouts/index.json`에 등록된 센터 도면을 검색하고 불러옵니다.
13. 대량 적재는 **박스 자동 적재**에서 팔레트·박스 규격과 수량을 입력합니다.
14. 작업 중에는 **브라우저 저장**을 누르고, 다른 PC로 옮길 때는 JSON으로 내보냅니다.

## 기준 도면 관리

공용 기준 도면은 저장소의 `layouts/` 폴더에 보관합니다. 앱에서 **기준 도면 → 현재 도면 JSON 저장**을 누른 뒤 내려받은 파일을 `layouts/`에 업로드하고 `layouts/index.json`에 센터명, 파일명, 규격, 태그를 등록하면 목록에 표시됩니다.

GitHub Pages는 정적 사이트이므로 웹페이지가 저장소에 직접 파일을 추가할 수는 없습니다. 직접 저장 기능은 GitHub OAuth/GitHub App과 토큰을 안전하게 보관할 별도 서버가 필요합니다. 개인 액세스 토큰을 프런트엔드 코드에 넣으면 방문자에게 노출되므로 사용하지 마세요. 파일 등록 방법과 `index.json` 예시는 `layouts/README.md`를 확인하세요.

## 데이터와 보안

- 별도 서버나 데이터베이스를 사용하지 않습니다.
- **브라우저 저장** 데이터는 현재 브라우저의 `localStorage`에만 저장됩니다.
- 다른 PC 또는 브라우저로 이동하려면 JSON 내보내기·불러오기를 사용하세요.
- 브라우저 데이터를 삭제하면 로컬 저장본도 삭제될 수 있으므로 중요한 도면은 JSON 파일로 보관하세요.

## 파일 구성

```text
index.html                 화면 구조
styles.css                 UI 스타일
app.js                     편집·저장·불러오기 로직
objects.js                 3D 설비 모델과 적재 계산
layouts/                   공용 기준 도면 JSON과 목록 파일
boot.js                    시작 오류 안내
vendor/                    Three.js와 카메라 컨트롤
licenses/                  오픈소스 라이선스
```

## 현재 적재 계산 범위

수동 적재는 박스 바닥면이 팔레트 또는 아래 박스 안에 들어오는지를 기준으로 높이를 맞춥니다. 총 수용량은 박스랙의 설정 용량, 각 팔레트의 이론 적재 용량, 팔레트에 속하지 않은 바닥·독립 적재 박스를 합산합니다. 팔레트 위 수동 박스는 팔레트 수용량에 이미 포함되므로 중복 합산하지 않습니다. 자동 적재와 팔레트 용량은 동일 규격의 직육면체 박스를 대상으로 박스 회전 방향과 최대 높이를 고려합니다. 중량 중심, 박스별 최대 하중, 혼합 규격 최적화, 구조 안전성은 계산하지 않으므로 실제 설비·적재 확정 전에는 별도 안전 검토가 필요합니다.
