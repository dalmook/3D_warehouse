GitHub에 도면 저장

별도 서버 없이 이 브라우저에서 GitHub API로 JSON 파일을 커밋합니다. 토큰은 저장하지 않고 창을 닫으면 지웁니다.

공개 저장소에 저장한 도면은 누구나 볼 수 있습니다. 실제 보안 시설·회사 도면은 공개 저장소에 올리지 마세요. 비공개 저장소에 저장할 때는 위 저장소 이름을 변경하세요.

토큰 발급: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens. 저장할 저장소만 선택하고 Contents: Read and write를 허용하세요.
