GET STARTED

만들고, 움직이고, 걸어보세요.

01 · 배치하기

자동 배치로 시작하거나 설비를 선택하고 바닥에 놓으세요. 드래그로 이동하고, R로 회전합니다. 실행 취소는 Ctrl+Z입니다.

02 · 시뮬레이션

재생 버튼을 누르면 입고→보관→검수·포장→출고 작업자가 이동합니다. 오른쪽 작업 지점을 선택한 뒤 빈 통로를 클릭해 동선을 바꿀 수 있습니다.

03 · 직접 걸어보기

WASD 또는 방향키로 이동합니다. 마우스 시점 고정 버튼 또는 화면 드래그로 둘러보세요. Q/E는 좌우 회전, Shift는 빠르게 걷기, Esc는 나가기입니다. 모바일은 방향 버튼과 화면 스와이프를 사용합니다.

GitHub 저장과 공유

로컬 자동 저장은 현재 브라우저의 임시 저장입니다. GitHub 연결 후 저장해야 다른 기기에서도 열 수 있습니다. 공유 링크는 보기 전용이며 실시간 다중 접속 게임이나 실제 직원 위치 추적은 아닙니다.
